# ToDo App Practice Project

This is a small JavaScript practice project built to learn how to create a simple to-do list app with DOM manipulation.

## What it does
- Add a new task from the input box
- Display the task in the list
- Remove a task with the delete button
- Use a colorful, animated UI for practice and styling experimentation

## Files
- `index.html` — page structure
- `style.css` — styling and animations
- `script.js` — JavaScript logic for adding and deleting tasks

## Notes
This project was created mainly for practice with JavaScript, so the CSS is intentionally vibe-coded and designed to look playful and modern rather than production-perfect.

## How to run
1. Open `index.html` in your browser.
2. Type a task in the input field.
3. Click the Add Task button.
4. Use the delete button to remove tasks.

## Purpose
A simple beginner-friendly project for practicing:
- JavaScript events
- DOM creation and updates
- element manipulation
- beginner UI interaction
